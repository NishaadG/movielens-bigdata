    Where the data lives

    Files in HDFS under /movielens, read from the NameNode. Each block is stored on two DataNodes (replication 2).

    NameTypeSizeReplication
    1. HDFS stores the raw CSV files
    2. Spark reads them and computes the statistics
    3. Cassandra holds the results
    4. This page reads from Cassandra
    Dataset: MovieLens, GroupLens Research, University of Minnesota.
